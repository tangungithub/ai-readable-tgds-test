# Easing Foundation 토큰 규칙

작성일: 2026-08-18
범위: Foundation 티어 `Motion/Easing/{ }` 토큰 네이밍·값 정의

---

## 1. 구조 원칙

- 전체 경로: `Motion/Easing/{step}` — Motion은 컬렉션(그룹), 토큰 이름 자체는 `Easing/{step}` 2단 구조.
- 기존 Foundation 컨벤션(`Scale/Step`, 예: Red/300, Radius/100)과 동일한 2단 원칙을 유지한다. Direction(Accelerate/Decelerate 등)을 별도 세그먼트로 분리하지 않는다 — 3단이 되어 컨벤션이 깨지기 때문.

## 2. 설계 논리 — Direction을 하나의 스펙트럼으로 합친다

큐빅 베지어 곡선에서 뽑을 수 있는 속성은 진입 기울기·진출 기울기·대칭성·곡률 강도·오버슈트 여부 5가지다. 이 중 진입/진출 기울기와 대칭성은 사실 독립된 두 개념(Accelerate, Decelerate)이 아니라 **"어느 쪽 끝이 느린가"라는 하나의 질문에 대한 양 끝 값**이다. 그래서 Accelerate ↔ Standard ↔ Decelerate를 diverging(중앙값 기준 양쪽으로 갈라지는) 스케일 하나로 표현한다. {step} 값이 500(중앙)에서 멀어질수록 그 방향으로의 편향이 강해진다.

이 방식은 "방향과 강도를 완전히 독립적으로 조합"하는 걸 포기하는 대신, `Motion/Easing/{ }` 구조를 깨지 않고 숫자 하나로 스케일을 표현할 수 있다는 트레이드오프를 가진다.

## 3. 기본 5단계

| Step | 의미 | bezier | 용도 |
|---|---|---|---|
| 100 | 강한 Accelerate | (0.7, 0, 1, 1) | 화면/큰 요소 완전 퇴장 |
| 300 | 약한 Accelerate | (0.4, 0, 1, 1) | 버튼 상태 종료, 일반 퇴장 |
| 500 | Standard (기준, 중앙) | (0.4, 0, 0.2, 1) | 대부분의 기본 전환 |
| 700 | 약한 Decelerate | (0, 0, 0.2, 1) | 일반 진입 |
| 900 | 강한 Decelerate | (0, 0, 0, 1) | 화면/큰 요소 완전 진입 |

## 4. Emphasized(오버슈트) 확장 규칙

**규칙: 끝자리 50은 해당 베이스 값에 오버슈트가 추가된 변형을 의미한다.** 이 규칙은 숫자만 보고는 유추되지 않으므로 반드시 이 문서로 명시해야 한다 — 그렇지 않으면 150을 "100보다 약간 강한 값"으로 오독할 위험이 있다.

| Step | 의미 | bezier |
|---|---|---|
| 750 | 약한 Decelerate + Emphasized | (0.05, 0, 0, 1.05) |
| 950 | 강한 Decelerate + Emphasized | (0.1, 0, 0, 1.15) |

**Decelerate 쪽에만 정의하는 이유**: 오버슈트는 "도착 지점을 살짝 지나쳤다가 되돌아오는" 움직임이라 요소가 멈추는 쪽(Decelerate/진입)에서만 자연스럽다. Accelerate(퇴장) 쪽에 오버슈트를 붙이면 실사용 사례가 거의 없다.

**정의하지 않은 값**: 150, 350, 550(Accelerate/Standard + Emphasized)은 규칙상 만들 수는 있지만, 실제로 쓰이는 컴포넌트 사례가 나오기 전까지는 정의하지 않는다 — 쓰이지 않는 단계가 열린 채로 남는 것을 막기 위함.

## 5. 향후 세분화 여지

200/400/600/800(각 방향 내 중간 강도)은 현재 정의하지 않는다. 50 오프셋(오버슈트 플래그)과 겹치지 않으므로, 실사용에서 5단계로 해상도가 부족하다고 확인되면 추가하는 방식으로 확장한다.

## 6. Semantic 연결

Duration과 Easing은 항상 짝으로 소비되는 "모션 토큰"이다. Semantic 티어에서 개별 참조 대신 세트로 묶어서 정의한다.

예: `Motion/Enter = Easing/700 + Duration/Base(250ms)`

이 연결로 2026-08-11 리뷰에서 지적된 "Duration·Easing Semantic 부재로 인한 참조 데드락" 항목이 해소된다.

## 7. 미결정 / 후속 확인 사항

- Step 500(Standard)의 bezier 값을 Material 관례값(0.4,0,0.2,1)으로 둘지, 완전 대칭형(0.4,0,0.6,1)으로 둘지 확정 필요.
- 200/400/600/800 중간 강도 단계의 실사용 필요성은 컴포넌트 감사 이후 재검토.
- Emphasized 조합(750/950)이 실제로 어떤 컴포넌트에 쓰일지 구체 사례 확보 필요.
