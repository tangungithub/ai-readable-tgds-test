## 🔒 지금 막혀 있는 것

세부 항목을 나눠 보니 **한 단위가 다른 단위를 붙잡고 있는 구조**가 드러났습니다.
아래 6개는 각각 여러 칸을 동시에 막고 있어서, 이것부터 풀지 않으면 나머지를 채워도 다시 뜯게 됩니다.

| # | 막고 있는 것 | 어디서 | 무엇이 막혀 있는가 |
|---|---|---|---|
| 1 | **계층 간 어휘 불일치** — Primary vs Brand 혼용, `Text Muted` 미정의 | [A2](docs/A-token/A2-semantic-theme.md) | A2 네이밍·사용·판별 + A4 전체. 어휘가 흔들리면 아래 규칙을 전부 다시 씀 |
| 2 | **State의 닫힌 목록 부재** | [B3](docs/B-component/) | A4 네이밍·판별. State는 Component 티어에서만 쓰기로 했는데 정작 목록이 없음 |
| 3 | **컴포넌트 이름 기준 집합 부재** | [D2](docs/D-naming/) | A4 네이밍 + `DENY-01` 자체. "DS에 없는 이름"을 판정할 기준이 없음 |
| 4 | **Duration·Easing·Shadow의 Semantic 부재** | [A5](docs/A-token/A5-collection-structure.md) | 참조 데드락 — Component가 참조할 상위가 없어 규칙상 불가능한 상태 |
| 5 | **Breakpoint 목록 미정의** | [C2](docs/C-layout/) | A3 Responsive 컬렉션 전체 (Mode 축이 정해지지 않음) |
| 6 | **DS 프로젝트 경계 미정의** | [D3](docs/D-naming/) | `DENY-03` — "외부에서 제작"을 판정하려면 외부가 어디인지 정의돼야 함 |

> **게이트웨이 Deny 3종은 전부 전제 조건이 비어 있습니다.** 게이트웨이를 먼저 만들 수 없는 이유입니다.

## 📐 판정 원칙

- **"문서를 썼다"는 ✅가 아닙니다.** 각 축의 체크 항목을 실제로 만족해야 ✅입니다.
- **네이밍 축은 enum이 하나라도 열려 있으면 🟡을 넘지 못합니다.** "등", "기타"로 끝나는 집합은 판별할 수 없습니다.
- **판별 테스트 축이 이 대시보드의 핵심입니다.** AI Readable = 설명 없이 판정 가능한 상태이므로, 이 축이 곧 AI Readable 여부입니다.
- 사용 규칙에 **금지 사항이 없으면** 그 축은 미완입니다. 금지가 없으면 판별할 것도 없습니다.

## 📁 문서 구조

```
docs/
├── 00-overview/      정의 · 구현 축 · 5요소 대조 · 로드맵
├── A-token/          규범 문서(token/foundation/semantic/component-token) · 단위 트래커 A2~A5
├── B-component/      B1~B5
├── C-layout/         C1~C3
├── D-naming/         D1~D3
├── E-design-code/    E1~E3
├── F-governance/     F1~F5
├── 90-materials/     발표 · 제작 자료 (규범 아님)
└── 99-reference/     근거 리서치

tokens/               모든 토큰 값의 정본 (DTCG 형식)
scripts/              생성기
src/tokens/           생성물 — 손으로 고치지 않는다
```

> B~F는 아직 미착수 단위가 많아 영역당 한 파일로 묶어 두었습니다.
> 작업이 시작되는 단위부터 A 영역처럼 파일을 분리합니다.

### 문서의 세 종류

| 종류 | 위치 | 정본 여부 |
|---|---|---|
| **규범** | `docs/A-token/token.md` 외 3개 | ✅ 규칙의 정본 |
| **값 등록부** | `tokens/*.tokens.json` | ✅ **값의 정본** — md와 어긋나면 이쪽이 맞다 |
| 트래커 · 리서치 · 발표 자료 | 그 외 전부 | ❌ 규범과 어긋나면 규범이 맞다 |

**규칙은 md, 값은 json.** 색 하나를 바꾸는 데 문서를 열 필요가 없고, 규칙 하나를 바꾸는 데 값 파일을 열 필요가 없다.

### ⚠️ 미결 — 생성기 재연결

`scripts/generate-tokens.mjs`는 아직 구 스펙(`docs/A-token/token-system.md` §1.6)을 입력으로 삼고 있어
`src/tokens/*` 생성물이 `tokens/foundation.tokens.json`과 어긋나 있습니다. 생성기를 `tokens/`로 재연결해야 합니다.
